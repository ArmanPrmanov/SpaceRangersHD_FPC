# 2026-09-28 — Phase 5 (networking)

Design: [docs/network.md](../network.md). Owner decisions this session: a remote
human's mid-day dialogue pauses the host's day and is answered on the client
(not auto-answered); hosting and joining get in-game menus as well as flags.

## Core (headless)

- Done:
  - Transport and deltas: `platform/net_native.c` (sockets, zstd with a
    reference prefix, XXH64), `NetTransport`, `NetDelta`, unit tests
    (9f2246a, 85b11ff).
  - Protocol, network thread, data hash (85b11ff); `THuman.Connected` and the
    game-layer hooks (a67dd66); host, client and session (d686996); headless
    drivers `--sim-net-host`, `--sim-net-join`, `--sim-net-leave-at` and the
    `tools/test.py` networked checks (7e638a9); docs (0bb7a1b).
  - Remote commands are queued per peer and applied in `Session.Humans` order
    once every peer is ready, so a networked game is deterministic however the
    commands arrived.
  - d84f38d: checkpoint loading was quadratic (`ReadExactValues`); a client
    load went from ~7 s to ~0.4 s.
  - `tools/test.py`: 3/3 saves pass, goldens unchanged. With 2 and 8 humans:
    client hashes match the host's every day, two runs agree, the host's log
    replays, and a client that leaves and rejoins gets its human back.
- Notes (debug build, 10 days, medians):
  - Whole state ~2.8-3.0 MB raw, ~530-560 KB zstd. Delta ~90-100 KB per day.
  - Films ~90-100 KB per day with 2 humans, 510-650 KB for all stars with 8.
  - Client load 350-450 ms (2 humans), 730-940 ms (8, nine processes on one
    machine). Host takes its state in 110-290 ms.
  - So a day costs a client ~0.2 MB, not the 11 MB the roadmap's risk
    section feared.
  - The headless hot-seat script now returns shop stock on takeoff
    (`tfReturnShopStock`), as the screens do; hot-seat hashes moved (not goldens).
- Known gaps: a disconnected human on automatic control keeps flying; states do
  not carry `ContinueUntilArrival`/`EndedTurn`; a remote command that raises on
  the host is dropped silently for the recorder; loose game-folder files are not
  in the data hash; chat is not shown; remote dialogue not yet sent.
